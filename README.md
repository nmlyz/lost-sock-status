lost-sock-status writes one line to a text file: the status update of a lost sock found inside the dog — the vet calls it an 'incidental finding' and the dog calls it delicious. The line was picked from 38 candidates by pairwise judging against the brief: a sock that ended up somewhere it should not be, reported in the vet's clinical words and closed by the dog's verdict, with the punchline as the last word.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). No network access needed; the same text, byte for byte, on every run. The line is 102 characters, a single line, and ends on its punchline. The program builds the line from three clauses — the found report, the vet's label, the dog's verdict — and checks the result against the entry gate (length, single line, no leading or trailing space, exact judged length) before writing it, then reads the file back to confirm the bytes match.
